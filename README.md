# ICT2104B — Object Oriented Programming II (Java)

## Module 3: Taking Control

This repository contains the seven Java programs completed for **ICT2104B — Object Oriented Programming II, Module 3: Taking Control**. The programs demonstrate Java **selection, iteration, switch statements, loops, and input validation** as required by the laboratory activities.

## Files Included

1. **ExamEligibility.java** — Determines a student's exam eligibility based on their attendance percentage.
2. **MobileMoneyMenuLoop.java** — Implements a repeating Mobile Money menu using `switch` and `do-while`.
3. **BodaFareTable.java** — Calculates and displays boda-boda fares for different distances using a `for` loop.
4. **PinValidator.java** — Validates a four-digit Mobile Money PIN using input validation and a `while` loop.
5. **SnippetA.java** — Demonstrates and corrects an assignment-versus-comparison error in an `if` statement.
6. **SnippetB.java** — Demonstrates and corrects a `switch` statement fall-through error by using `break`.
7. **ResultProcessorValidated.java** — Calculates a student's weighted final mark and grade while validating all entered marks.

## Concepts Demonstrated

* `if`, `if-else`, and `else-if`
* `switch` statements
* `for` loops
* `while` loops
* `do-while` loops
* Input validation using `Scanner`
* `hasNextInt()` and `hasNextDouble()`
* Boolean conditions
* `break` statements
* Weighted calculations
* Grade classification

## How to Run

Make sure **Java JDK** is installed on your computer.

Open the terminal in the project folder and compile a file using:

```bash
javac ExamEligibility.java
```

Then run it using:

```bash
java ExamEligibility
```

Replace `ExamEligibility` with the name of any other Java file you want to run.

### Example

```bash
javac PinValidator.java
java PinValidator
```

## Assignment Requirements

The programs were developed according to the Module 3 laboratory activities, which require each program to compile and run without errors, use appropriate control structures, include `break` statements where required, and ensure validation loops terminate when valid input is entered.
